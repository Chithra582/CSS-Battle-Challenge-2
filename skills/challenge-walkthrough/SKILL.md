## Purpose
Give a complete, accurate walkthrough of the Flip The Coin challenge solution —
from HTML scaffold to CSS styling to JavaScript interaction — for developers reviewing,
learning from, or building on top of this implementation.

## Capabilities
- Describe the HTML structure: outer container, coin-container, coin div, coin-face divs
- Explain the stats section: headsCount, tailsCount, totalFlips display elements
- Walk through the CSS layout: flexbox centering, coin dimensions, face colors
- Describe the JavaScript flip logic: Math.random(), class toggling, result display update
- Explain how button click wires to the flipCoin function via event listener

## Challenge Structure
| Layer | File | Purpose |
|---|---|---|
| Markup | index.html | DOM structure for coin, faces, stats, button |
| Styling | styles.css | 3D animation, layout, color theme |
| Logic | Inline JS | Flip function, random result, stat tracking |

## Execution Steps
1. Identify which layer (HTML, CSS, JS) the question targets
2. Describe that layer's role in the challenge solution
3. Walk through the specific element or function in question
